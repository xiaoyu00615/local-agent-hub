## 停线 / 降级标准

- **网络或网页无法证明目标对话身份**：停止自动投递；仅允许保守的 Hub 内预览/人工确认模式。
- **WorkBuddy 只能可靠 G0/G1**：仅观察或受监督任务；不宣称可多步/无人值守。
- **第二真实 Adapter 不可用**：记录阻塞或正式申请调整 V1 范围，不得用 Mock 假冒替代。
- **外部提交未知**：核对原 Attempt，不创建第二次副作用尝试。
- **人工接管**：保留阻断直到用户在可信 UI 明确批准恢复。
- **预算/权限不足**：等待授权、降级到许可的能力或停止，不自行扩大范围。
- **Windows 主机睡眠/关机**：本地无法保持执行，只能保留状态并在恢复后核对。

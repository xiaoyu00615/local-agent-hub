## 批准前需由用户明确接受的政策边界

1. **Core 的安全保证范围**是 Hub 掌控的受控操作，不是对所有同用户 Windows 进程的硬拦截。
2. **第一版开发者模块**限内置与用户明确信任来源；不宣称沙箱执行第三方不可信代码。
3. **网页原会话自动查询和回传**继续作为首版目标；手动回传只是降级，不视为目标实现。
4. **可信 Test Profile** 须事先批准并清晰告知可能写入；强隔离作为独立等级。
5. **不确定副作用与人工接管**时不得未经确认执行新写入。

一旦用户批准，形成明确 ADR 决策记录；其他关于 ID 字段、ACK 精细状态、网页 DOM 适配、进程隔离和 Test Runner 实现仍保留 F2 或 E01–E07，不得凭审批跳过试验。

# 06｜首版验收矩阵 V1.1

**状态：REVIEW DRAFT；以下是上线/开发门槛，不代表已通过测试**

| ID | 场景 | 通过条件 | 必要证据 |
| --- | --- | --- | --- |
| M-01 | 导入本地开发者模块 | 无需修改或重编 Core；成功能力注册 | Manifest 验证和握手日志 |
| M-02 | 模块移除/崩溃 | Core 和无依赖任务可继续；受影响节点正确阻塞 | 运行日志和 DB 状态 |
| M-03 | 模块升级 | 在执行任务不被静默重启，版本可回滚 | Version 和 Revision 记录 |
| A-01 | 绑定网页 AI | 不把错误标签页/对话识别为原会话 | Binding 身份检查 |
| A-02 | WorkBuddy GUI 一轮任务 | 正确提交、观察、收集且轮次归属明确 | 发送证据/终态/回复定位 |
| A-03 | DSH（或第二种驱动） | 同一能力契约适配，不依赖具体 App | 可替换适配器测试 |
| S-01 | 人工接管 | 新写入立即阻止；旧外部动作真实状态保留 | Ownership Epoch、审计记录 |
| S-02 | 人工恢复 | 即使对账通过也未自动写入；显式批准后才可续行 | 用户决策及授权版本 |
| S-03 | 目标会话切换 | 结果不交付错误会话，不错误复用许可 | 绑定代际和交付日志 |
| W-01 | 授权工作区只读 | 可查询内部文件，拒绝越界/链接绕过 | 访问记录、拒绝原因 |
| W-02 | 数据外传权限 | 无 External Disclosure Grant 时绝不发送内容 | 独立拒绝事件 |
| W-03 | 网页 AI 工具循环 | 能发出候选请求、通过检查、读取片段、准确送回原会话 | 端到端链路与交付 ACK |
| T-01 | 测试方案执行 | 只调用批准 Profile，记录退出码、日志、产物 | 执行报告与变更清单 |
| T-02 | 非法终端请求 | 任意 Shell/扩大执行范围被拒绝 | Permission Gateway 决策记录 |
| WF-01 | 完整链路 | 文件→AI→审批→Agent→测试→验收→交付 | 完整 Run/Node/Attempt 事件 |
| WF-02 | 中途重启 | 已完成节点不无声重做，不确定节点进入对账 | 恢复事件和外部核验 |
| WF-03 | 重复消息 | 不无提示造成同一副作用再执行 | Idempotency/Attempt 日志 |
| UI-01 | 仅通过 Web 管理 | 无需编辑 DB/终端即可安装、授权、运行和恢复 | 用户操作验收 |
| UI-02 | 断线/刷新 | UI 恢复正确权威状态，历史记录完整 | 快照 + 事件序号核验 |

## 阶段门槛
G0 文档跨模块冲突清理及 P0 阻塞解除。
G1 模拟 Adapter 通过协议/恢复/权限测试。
G2 文件只读查询与网页结果回传闭环。
G3 WorkBuddy GUI 一轮任务和人工接管验收。
G4 第二种驱动 Adapter 可替换性验收。
G5 受控 Test Runner 和副作用审计验收。
G6 核心重启、模块重连、重复请求、错会话的故障注入验收。
G7 无需开发者介入的 Web Console 操作验收。

**不变量**：不同阶段的完成定义不能因 UI 方便而混淆；任何涉及外部副作用而事实未知的失败，必须保留未知状态。
